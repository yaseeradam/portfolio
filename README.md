## ✨ Features & Highlights

- 🛸 **360° Revolving Technology Orbit**: Interactive 360-degree circular orbit ring revolving 8 authentic technology badges (*React, TypeScript, Node.js, Flutter, Laravel, AI Systems, Next.js, Tailwind*) around a 3D avatar with upright counter-rotation.
- 🎨 **Luxury Dark Theme & Glassmorphism**: Tailored warm dark aesthetic (`#0a0705`) featuring custom glass cards, glowing ambient 3D orange glass art background graphics, and smooth backdrop blurs.
- 🚀 **Featured Product Showcase**: High-contrast project cards featuring custom color themes, technology tags, open-source repository links, and direct live Vercel application links.
- 📱 **Fully Responsive Layout**: Built with a mobile-first design, interactive drawer navigation, and smooth section scrolling.
- 📄 **Integrated Resume Download**: Direct one-click download for `resume.pdf` integrated directly into the navbar.

## 🚀 Quick Start & Development

### 1. Clone the Repository
```bash
git clone https://github.com/yaseeradam/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
# Or on Windows WASM environment:
npx next dev --webpack -p 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application live.
